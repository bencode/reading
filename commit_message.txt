feat: Implement article categorization and tagging with LLM and Yoyo migrations

This commit introduces significant enhancements to the article processing pipeline:

- **Database Schema Update:**
    - Integrated `yoyo-migrations` for version-controlled database schema management.
    - Added `categories` and `tags` tables.
    - Created `article_categories` and `article_tags` join tables for many-to-many relationships.
    - Modified the `articles` table to remove the old `tags` column and link to `categories`.
    - Pre-populated the `categories` table with predefined categories, including 'Other'.

- **LLM-Powered Categorization and Tagging:**
    - Modified `scraper.py` to leverage the LLM for automatic article categorization and tag generation during summarization.
    - Updated LLM prompts to request structured JSON output for summary, category, and tags.
    - Improved robustness of LLM response parsing to handle various JSON formats.

- **Expanded RSS Feeds:**
    - Integrated a comprehensive list of RSS feeds from `briefings/02.md` to enrich content sources.

- **Refactored Database Operations:**
    - Updated `insert_article` to handle category and tag associations.
    - Removed direct table creation from `init_db` as migrations now manage schema.

This feature significantly enhances the "Reading" application's ability to organize and filter content, providing a richer user experience.
